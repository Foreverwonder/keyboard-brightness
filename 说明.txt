键盘亮度调节  v3.1
============================================================

这是什么
------------------------------------------------------------
把你键盘上的两个键，改成屏幕亮度的「暗一点」和「亮一点」。

按下去会真的改屏幕亮度，并且弹出 Windows 自己那条亮度条
（就是调音量时冒出来的那种，圆角、半透明、有动画）。

默认占用的是「停止」和「上一曲」两个键。想换成别的，往下看。


怎么用
------------------------------------------------------------
双击「键盘亮度.exe」就行。

启动后它待在后台，右下角托盘区有一个图标。鼠标放上去会显示
「键盘亮度调节」。它不弹窗、不打扰你。

开机自动运行已经设好了，不用每次去点。


想换按键
------------------------------------------------------------
用记事本打开「配置.ini」，找到 [按键] 那一段：

    变暗=MediaStop
    变亮=MediaPrev

把等号后面换成别的键名就行。能写的名字：

    MediaStop  MediaPrev  MediaNext  MediaPlayPause
    VolumeUp   VolumeDown VolumeMute
    BrowserBack  BrowserForward  BrowserRefresh  BrowserHome
    F5  F6  F7  A  B  1  2
    ^!F5   （Ctrl+Alt+F5，^ 是 Ctrl，! 是 Alt，+ 是 Shift）

保存，然后右键托盘图标选 Reload This Script（或者关掉重开）。

懒得查键名？把等号后面改成一个问号：

    变暗=?

保存后重新打开程序，它会「滴」两声，在屏幕左上角提示你按键。
你在键盘上按一下想用的那个键，它就自己记住了，还会把键名写回
配置文件。不用再来问谁。


想改手感
------------------------------------------------------------
配置里 [亮度] 那一段的「步长」就是每按一下变多少。
现在填 5，也就是按二十下走完全程。觉得太粗就改 3 或 2。

按住不放不会连发，按一下就是一格，跟音量键的手感一致。


想让它只在特定键盘上生效
------------------------------------------------------------
[设备] 那一段可以填一颗键盘的硬件 ID，意思是：只有这颗键盘插着
的时候才响应，拔掉自动停用，插回来自动恢复，不会干扰笔记本自带
的键盘。

不填（留空）= 任何键盘都能触发。现在这份配置是留空的，因为安装的
时候不知道你的键盘是哪颗。

查自己键盘 ID 的办法写在 GitHub 的 README 里，查到了填进
「键盘ID=」后面就行。


出问题看哪里
------------------------------------------------------------
文件夹里会生成一个 bright.log，用记事本打开能看到每次按键的记录，
比如「亮度 65 → 60」。

完全没反应，看最后几行：

    有「键盘在位 → 映射启用」   脚本活着、键盘认到了，问题在键名
    有「键盘不在 → 映射停用」   键盘ID 填的和实际这颗对不上
    连「启动」都没有            脚本根本没跑起来

配置改完不生效，多半是没重启程序——配置只在启动时读一次。


想关掉
------------------------------------------------------------
临时停用：右键托盘图标 → Suspend Hotkeys（打勾就暂停响应）。
彻底不用：右键托盘图标 → Exit，然后运行「卸载.bat」。
只是不想开机自启：把配置里 [其他] 的「开机自启」改成「否」，
保存后重开一次程序，它会自己去删掉注册表里那一条。


一个坑
------------------------------------------------------------
别同时开两份。这个程序只保证「同一个路径只跑一份」，你要是把
备份文件夹里的 exe 也点开了，按一下会跳两格（两份各调一次）。


这个文件夹里都有什么
------------------------------------------------------------
键盘亮度.exe    程序本体，双击它。它其实是官方 AutoHotkey 引擎
                原样改了个名，没改过一个字节
键盘亮度.ahk    程序源码，纯文本，懂的人可以看，别改
配置.ini        你要改的就是这个
说明.txt        本文件
bright.log      运行日志，可以随时删
